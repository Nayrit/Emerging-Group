# Emerging Group Website

Corporate website for **Emerging Group Bangladesh**, built with Next.js (App Router), React, and Tailwind CSS.

## Run locally

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Homepage
- `/about` — Executive overview, mission, milestones, leadership
- `/businesses` — Six verticals index
- `/businesses/[slug]` — Vertical detail pages
- `/sustainability` — Triple-bottom-line
- `/investors` — Investor centre
- `/newsroom` + `/newsroom/[slug]` — News
- `/careers` — Culture + filterable open roles
- `/contact` — Head office, enquiry routing, form
- `/privacy`, `/terms`

## Brand

Logos live in `public/brand/` (`logo.png`, `logo-mark.svg`, `logo-wide.jpg`).

Design language follows the provided corporate design canvas (Archivo + Newsreader, navy `#0B2240`, blue `#1548B0`).
